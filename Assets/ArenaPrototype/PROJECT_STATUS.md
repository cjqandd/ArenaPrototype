# 项目需求与完成状态

更新时间：KayKit Adventurers 首版角色身份预制体接入后。

## 本轮新增而非第一阶段已有内容

- 统一的玩家动作阶段模块，剑与踢击共用相同计时和取消规则。
- 闪避取消后摇，但不能取消前摇或有效帧。
- 喝彩等级开始实际提高玩家生命与架势伤害。
- 命中、格挡、破盾、失衡、击杀和受伤的屏幕文字反馈。
- 敌人攻击协调器，第三名敌人会等待攻击名额。
- 两次场间三选一强化，并在HUD持续显示已选强化。
- 集中式功能HUD、难度选择、拾取提示、暂停、帮助和胜利界面。
- 玩家头顶临时生命/闪避条移入HUD，正式敌人生命条移除。
- 所有游戏内灰盒界面文字改为中文，并增加 Windows 中文系统字体回退。
- 建立美术资源分区、购买检查、导入流程、命名规则和资源台账方案。
- 建立统一角色美术目录和灰盒回退接口，并在不改变玩法判定的前提下接入 8 个 KayKit 角色实例。

## 尚未完成的主要工作

1. KayKit 角色视觉的人工试玩验收；正式武器、竞技场模型以及战斗、受击、死亡动画。
2. 链刃真实链条运动、专属连段、命中特效和手感调校。
3. 受击、格挡、破盾、喝彩、武器和界面的音效；环境音乐与观众声音。
4. 正式VFX、项目内中文字体、图标、界面动效和视觉规范。
5. 世界观文案、角色设定、叙事和未来可能增加的多语言本地化。
6. 主菜单、设置、存档、键位重绑定、画质选项和正式退出流程。
7. 正式平衡、性能检查、打包发布和目标平台适配。
8. 本轮新功能的人工整体验收；代码编译与静态复核不能替代手感测试。

## 明确不做

- 联机、匹配、服务器和多人同步。
- 当前阶段购买外部资源；等确认具体资源需求和格式后再进行。
